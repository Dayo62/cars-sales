Ciao Car Shop - Car Sales Management System
Overview

Ciao Car Shop is a console-based car sales management system developed in C. The program allows users to buy cars, view sales records, view available car stock, and save sales data to a CSV file.

This project demonstrates core programming concepts such as structs, arrays, pointers, file handling, functions, conditional statements, loops, and menu-driven program design.

Features
  - Menu-driven console interface
  - Buy cars from available stock
  - View available car models
  - View recorded sales
  - Track customer name, age, selected car model, car type, quantity, and total price
  - Apply a 5% discount for eligible customers aged 18–25
  - Validate customer age and driving licence eligibility
  - Update car stock after a purchase
  - Save and load sales data using a CSV file
  - Generate a sale ID using time-based values

Car Models Included
  - Fiat
  - BMW
  - Maserati

Each car model includes different car types, prices, and stock quantities.
